# 🧮 Calculadora em Java

Projeto desenvolvido em Java para praticar lógica de programação e conceitos básicos da linguagem.

## 🚀 Funcionalidades

- Adição
- Subtração
- Multiplicação
- Divisão

## 🛠️ Tecnologias

- Java
- Git
- GitHub

## 📚 Objetivo

Este projeto foi desenvolvido como parte do meu processo de aprendizado em programação, com foco no desenvolvimento de aplicações utilizando Java.

## ▶️ Como executar

1. Clone este repositório.
2. Abra o projeto em uma IDE, como IntelliJ IDEA, Eclipse ou VS Code.
3. Execute o arquivo `Calculadora.java`.
